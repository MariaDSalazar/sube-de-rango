# Sube de Rango

Juego web para practicar la normalización de tablas, de la primera a la quinta forma normal, con lecciones cortas al estilo de las apps de idiomas.

## Cómo se juega

- Escribe tu nombre y tu apellido y avanza por el camino: cada círculo es una lección que se abre al terminar la anterior.
- Cada unidad trata una forma normal (1FN, 2FN, 3FN, FNBC, 4FN y 5FN) con un caso de un torneo de videojuegos: la tienda, el hotel, la sala LAN, el catálogo y el arbitraje.
- En cada ejercicio tocas celdas, filas o encabezados, armas tablas con fichas, emparejas conceptos o eliges hasta qué forma normal llega una tabla. Luego pulsas «Comprobar».
- Si aciertas, ves por qué así; si no, por qué tu elección no sirve y lo intentas de nuevo. Cada error cuesta una vida.
- Al terminar obtienes un informe por tema y una constancia que puedes copiar o imprimir.

El avance se guarda solo en tu navegador. El juego no envía datos.

## Cómo se corre

Es una página estática: abre `index.html` en un navegador actualizado o publícala con cualquier servidor de archivos.
